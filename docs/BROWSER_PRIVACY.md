# DSU IDE Companion 隐私说明

更新日期：2026-10-11

DSU IDE Companion 用于连接用户本机的 DSU IDE，导入在线评测题目并协助提交代码。扩展没有开发者运营的云端数据收集服务，不内置统计或广告 SDK。

- 配对令牌和端口仅保存在浏览器本地存储中，用于认证 `127.0.0.1` 上的 DSU IDE。令牌不上传至开发者服务器，也不启用浏览器同步存储。
- 在支持或经用户授权的 OJ 页面上，扩展读取题目地址、题面和样例；用户点击导入后，通过本机连接发送到 DSU IDE，并保存到用户做题文件夹。
- 用户在 IDE 发起提交后，扩展可领取本机的源码与语言信息，使用当前浏览器的 OJ 登录会话向对应 OJ 提交。源码与请求受该 OJ 自身的隐私政策约束。
- 不收集 OJ 密码，也不将 Cookie 或 CSRF 令牌传给 IDE。提交过程可能在 OJ 页面中使用必要的 CSRF 信息；该信息不发往开发者服务器。
- 不读取普通浏览历史。脚本在清单列出的 OJ 页面以及用户主动授权的站点运行；自定义网站的权限可以从浏览器扩展设置中撤销。
- 用户打开工具栏面板时，只查询当前活动标签以判断是否支持导入；没有请求全局 `tabs` 或浏览历史权限。面板不会自动导入或发起提交。
- 点击设置页「断开配对」删除配对令牌。卸载扩展会清理其浏览器存储；IDE 工作区中的题目和代码仍由用户自行管理和删除。

发布到商店前，发布者需在商店填写有效的支持联系方式，并将本说明发布到公开可访问的页面。此说明仅适用于 DSU Companion，不替代所访问 OJ 或桌面应用其他组件的隐私说明。
