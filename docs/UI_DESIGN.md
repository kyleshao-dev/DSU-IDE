# DSU IDE 界面设计

DSU 的界面由本项目独立设计和实现。用户指定的 ShortestPath IDE 仅用于理解竞赛工具应减少干扰的目标；本次只阅读其公开功能说明，没有引入其界面代码、样式、图片或文案。

## 起始页

以题目为入口：有工作区时显示题目链接输入框、默认语言和已导入题目；没有工作区时只显示打开做题文件夹。工具链、OJ 配置、模板和浏览器配对收在「设置」菜单。使用 DSU 自己的括号标识、单色分隔线和主题原生颜色，避免重复卡片和装饰。

默认隐藏活动栏、状态栏，编辑器只显示当前标签。有工作区时，主页和做题界面共用左侧原生文件目录，按 OJ 文件夹展示代码，不再单独显示 DSU 题目树。点击已导入代码文件会将代码放入第一栏，并同步对应题面与样例；新建、重命名、删除使用 VS Code 原生操作。侧栏可随时折叠，并通过主页设置菜单中的「题目与文件」重新打开；编辑器标题栏的主页按钮和 `DSU: 打开主页` 命令可以随时返回。主页支持重启恢复。

## 做题

代码、原站题面和样例沿用已有三栏流程。样例顶部常驻「一键测试」「提交」；题面、编辑样例、切换语言收在「更多」。用紧凑的行和分隔线替代大卡片，显示通过数及每组结果。AC 的实际输出默认折叠，失败输出及诊断默认展开。原样输入/输出、样例编辑和提交回执功能保留。

界面精简通过公开的工作台默认设置、DSU 内置扩展和本项目 Webview 实现，不增加第三方 UI 框架、远程字体或图像请求。用户已有的显式设置可以覆盖新的默认值。设置中可恢复 `workbench.activityBar.location`、`workbench.statusBar.visible`、`workbench.editor.showTabs`；配置目录默认从文件列表隐藏。

## 验证

核心检查、浏览器主页/样例测试、真实交付应用做题流程，以及中文/英文启动和主页重启恢复测试。截图在 `dist/validation/`，当前 macOS arm64 交付包在 `dist/release/`。Windows/Linux 仍需执行对应平台验收。
