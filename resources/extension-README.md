# DSU IDE 内置做题工作台

DSU IDE 的内置扩展，提供 OJ 题目导入、代码归档、样例编辑和测试、浏览器提交以及代码模板补全。

此 VSIX 是开发附件，需要支持 browser proposed API 并允许 `dsu.dsu-ide` 使用该 API 的 Code OSS 定制版本。它不包含桌面引擎或各语言编译器。

打开并信任做题文件夹后，在命令面板执行：

- `DSU: 开始使用：选择默认语言`：初始化工作区。
- `DSU: 检查语言环境`：检查编译器、运行时是否在 PATH 中。
- `DSU: 打开内置浏览器`：打开题目，点击页面按钮导入。
- `DSU: 一键测试样例`：运行本地样例；面板支持新增、修改和删除样例。
- `DSU: 复制浏览器配对信息`：一次复制令牌与端口，连接 Chrome / Edge Companion；旧版令牌仍可粘贴使用。
- `DSU: 保存选中代码为模板`：设置补全关键字。

配置保存在 `.dsu/config.json`，包含 17 种语言预设、OJ 解析及提交规则、模板和运行限制。编译器需自行安装。

洛谷提交返回受理记录，不代表最终 AC。Codeforces / AtCoder 表单提交后需在 OJ 页面查看结果。需要验证或登录时不会自动重试。

完整源码附带 BUILD、CONFIGURATION、OJ_SUPPORT 和 VALIDATION 文档，请以交付版本中的验证记录为准。
